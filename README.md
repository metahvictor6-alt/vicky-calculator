# Vicky Calculator

A basic, responsive calculator that runs in any modern browser and can be installed on a phone from the browser menu.

## Run it

Open `index.html` directly in a browser, or serve the folder locally for the offline app features:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

Vicky supports addition, subtraction, multiplication, division, percentages, decimals, delete, keyboard input, and offline caching when served over HTTPS (or localhost).
